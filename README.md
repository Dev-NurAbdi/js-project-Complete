# 📖 SiraajHub
<img src="Assets/mockup-main.png" alt="SiraajHub Mockup" width="100%"/>
🌟 Overview
SiraajHub is a modern Quran learning platform designed to help users read, understand, and memorize the Holy Quran.

The platform provides:
* 📖 Read the Holy Quran
* 📚 Explore Tafsiir & Somali Translation
* 🔍 Search Surahs Easily
* 📅 Quran Memorization Plans
* 🌙 Dark / Light Mode
* 📱 Fully Responsive Design
* 📞 Contact & Support Section

---

## 🖥️ Features

### 📖 Read Quran
* Read Quran in Uthmani script.
* Clean and distraction-free reading experience.
* Quick Surah search functionality.

### 📚 Tafsiir & Translation
* Somali Translation (Sheekh Yacquub).
* Easy-to-read verse-by-verse layout.
* Dynamic loading from Quran APIs.

### 📅 Memorization Schedule
Choose a memorization plan that fits your lifestyle.
| Pages Per Day | Days Per Week | Duration  |
| ------------- | ------------- | --------- |
| 3 Pages       | 5 Days        | 10 Months |
| 3 Pages       | 4 Days        | 12 Months |
| 2 Pages       | 5 Days        | 15 Months |
| 2 Pages       | 4 Days        | 19 Months |
| 1 Page        | 5 Days        | 30 Months |
| 1 Page        | 4 Days        | 37 Months |

### 🌙 Dark Mode
* User preference saved using Local Storage.
* Smooth switching between light and dark themes.
### 📱 Responsive Design
Optimized for:
* 💻 Desktop
* 📱 Mobile
* 📟 Tablet
## 🛠️ Technologies Used
* HTML5
* CSS3
* JavaScript (Vanilla JS)
* Quran.com API
* QuranEnc API
* Font Awesome
